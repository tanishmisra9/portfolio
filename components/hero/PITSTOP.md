# Hero pitstop (`use-pitstop.ts`, `scatter-name.tsx`, `hero.tsx`)

(Root `CLAUDE.md` is git-ignored in this repo, so these notes live next to the code. Merge into `CLAUDE.md` if wanted.)

Clicking the name runs a pit stop with **4 tires** (TL `TAN`, TR `ISH`, BL `MIS`, BR `RA`), not 11 letters: tires fly toward their own corner → snap back one by one → the whole name slides off right → re-enters from the left (as if the page wraps around). Phases are `HERO_PHASE` (`lib/state-machines.ts`, tested by `npm run check:states`); clicks are ignored unless `idle`. Letters stay separate spans only for the cursor magnet; the pit-stop offset lives on the two group spans each `ScatterName` renders. There is **no blur or opacity animation** any more (a blur-fade-in was tried and rejected by the user; the old version also kept `blur(0px)` layers on all 11 letters): the drive wrapper in `hero.tsx` only animates `x`.

- **One sound, one timeline.** `public/sfx/pitstop.mp3` (5.24s, all baked into one file so `play()` runs inside the click gesture: iOS rule, assumed not tested on a device) = **whoosh 8 ×4** at 0/0.16/0.32/0.48s (`LAUNCH_MS` − 40: one per chunk as it splits; +60 was tried and felt late because the whoosh hits instantly while a tire's easeIn start barely moves) → the original Short through **one filter chain with no gaps** → **wheel-gun burst 0.92–1.57s** (the "pit stop" sound as the tires rejoin; one continuous rattle with no hits of its own) with **four impact hits on top, one per tire, at 1.00/1.18/1.36/1.54s** (= `BOLT_MS` + `SNAP_S`, the instant each tire lands; each hit = synthetic pitch-dropping thump + noise crack + a 110ms slice of the real gun rattle, and the burst is ducked under each so they pop) **crossfaded 0.35s (equal power, 1.40–1.75s) into the engine growl** (rises from 1.68s, to 2.82s) → **drive-off from ~3.15s, engine rev peaks ~3.75s** → **whoosh 9** starting 3.19s, peaking 4.35s as the name re-enters from the left. Source map: stretch X = source 5.80–6.80 (clip = source − 5.05) crossfaded into stretch Y = source 7.00–9.96 (clip = source − 5.60 for source ≥ 7.00). `LAUNCH_MS` / `BOLT_MS` / `DRIVE_MS` in `use-pitstop.ts` are the tuning knobs; **the whooshes are mixed in at fixed times, so re-mix the clip if `LAUNCH_MS`, `DRIVE_MS`, `DRIVE_S` or `ENTER_PAUSE_MS` change** (re-entry starts at DRIVE_MS + DRIVE_S + ENTER_PAUSE_MS = 4.25s audio-time; whoosh 9's peak is 1.16s after its start, so it starts at re-entry + 0.1 − 1.16). Each tire **slams home** (`SNAP_S` = 160ms tween, ease `[0.45, 0, 0.8, 0.6]`: arrives at speed and stops almost dead (the last control point was 0.5, "dead cut", until the user asked for ~5% less snap; raise toward 1 to soften more, the landing instant doesn't move), measured landing 150–167ms after its start): the old soft spring took 150–300ms to settle onto home, so there was no single instant for a sound to hit, and it read as mushy; the drive-off is a soft easeInCubic (0.55s) moving fast as the rev peaks; then a 0.35s pause (`ENTER_PAUSE_MS`) off-screen and a 0.3s easeOut re-entry (`ENTER_S`). The timeline anchors to the audio's `playing` event (a slow first load can't desync the snaps); if `play()` is rejected, or `playing` hasn't fired within `SOUND_START_CAP_MS` (500ms), it runs silently from the click, and in the second case the audio is **paused** (it used to keep loading and then play ~1s out of sync with every snap). Reduced motion: no pit stop and no sound (the clip alone, with nothing moving, read as unexplained noise).
- **Lesson: never stitch separately-filtered cuts, and don't leave a lull between sounds.** The first clip joined three source pieces with different highpass/denoise settings, digital-silence gaps and 30–40ms fade-outs, and the user could "feel one track ending and a new one playing" (measured: near-silent frames at 1.62–1.79s, a 35.7 dB cliff at the growl→drive-off join). A continuous region with one filter chain fixed the gaps (0 near-silent frames, worst 10ms level change 6.3 dB), but the 0.66s lull of ambience between burst and growl still read as two sounds, so the burst and growl are now crossfaded over the same bed (lull measured as time >6 dB under the quieter surrounding peak: 0.80s → 0.32s). To re-check any cut: count 10ms frames below −70 dB and the largest frame-to-frame drop across the span that should be continuous (must be ~0 and small), and measure the lull. Denoise was also tried: `afftdn` at nr 10→40 only moved the ambience bed by ~1.2 dB (the bed sits in 160–1280 Hz, right where the growl lives, and is only ~3 dB under the drive-off engine), so it isn't worth the artifacts.
- **Vertical sauce** (`LAND_KICK_PX` 4, `DRIVE_SQUAT_PX` 3, `DRIVE_LIFT_PX` −2, `ENTER_KICK_PX` 5, `wobbleSpring` damping 13; first tried at 7/6/−4/10 with damping 11 and the user said "a bit too noticeable", so these are about half; a kick of 0 turns that one off): only on moments that already have a sound or an exact instant, no continuous bobbing. Each tire is kicked down at its landing and wobbles back; the name squats as it starts to drive off and lifts as it accelerates; the re-entry lands with a bigger kick and wobble. All transform-only, one new MotionValue (`driveY`) on the drive wrapper. **Gotcha:** `MotionValue.set()` does not reset velocity, so a spring started right after a fast tween inherits its speed: without `velocity: 0` in `wobbleSpring` the tire kicks peaked at 400–1700px instead of 7px (caught by sampling `getComputedStyle().transform` every frame; measured at the current amounts: tire kicks 3.6px / re-entry 4.6px with ~1px rebound, everything back at 0, landing times unchanged).
- **Engine rumble** (`RUMBLE_PX` 2.4, was 1.2 and the user found it "not noticeable enough"; `RUMBLE_HZ` 15, `RUMBLE_PEAK_MS` 2820; `RUMBLE_PX` 0 turns it off): the one deliberate exception to "no continuous motion", because the growl is the loudest stretch and the name otherwise sat dead still from the tires settling (~2.0s) to `DRIVE_MS`. One `animate` over pre-built keyframes on `driveY` (no rAF loop): vertical only, sign alternating 30×/s with small per-beat jitter, each swing `easeInOut` (one ease per segment; `linear` made a triangle wave with instant reversals that read as a mechanical buzz), under a smoothstep swell that peaks with the growl, last keyframe 0; the drive squat starting on the same value stops it. Measured at 2.4: rumbles 2.07–3.35s audio-time, peak 2.34px, 33 reversals, first-third amplitude 0.81px vs last-third 2.34px, squat still 3px, ends at 0,0.
- **Lesson: a sound only "hits" if the picture has one exact instant to hit.** "The chunks coming in don't hit, it feels mushy" had two causes: a soft spring with no clear landing, and a continuous burst with no impacts. Fix = fixed-duration slam + one hit per landing + ducking the burst under each hit. Verify with a level-jump check at each landing time (loudest 5ms frame from just before to 30ms after, minus the mean level of the 50ms ending 10ms earlier; the decoded mp3 lags its nominal time by only ~5ms, a wrong offset here made the first reading look half as punchy): with hits 9.7–15.6 dB (mean 11.7) vs 2.8 dB for the same clip without them. Re-mix the clip whenever `BOLT_MS` or `SNAP_S` change.
- **Whoosh source.** "20 CINEMATIC WHOOSH Sound Effects (No Copyright)" on YouTube (id Hj7-pltIVng, 77s, no chapters; on-screen labels "WHOOSH N"). Found by `silencedetect` (exactly 20 sounds, in order) and confirmed against the on-screen labels. Whoosh 8 = source 25.21–25.57s (a 0.3s hit-then-decay burst); whoosh 9 = 26.43–28.48s (a 2s swell, peak at 27.59s).
- **Lesson: identify the sounds before timing them.** The first three timings were wrong because the clip was cut from spectrogram analysis alone and the roles were mislabelled: the source's 7.3–8.4s block is the car's engine *growl*, not gun noise, and the real pit-stop gun burst (source 5.95–6.66s) had been placed at the split, then cut entirely. Only the user's ears settled it. If the clip changes, have the user confirm what each section is before tuning times. Cut points are from the first of two stops in the Short: gun burst 5.95–6.66, growl 7.26–8.46, drive-off 8.46–9.96.
- **Audio latency offset.** The `playing` event fires *before* sound reaches the speakers, so the picture ran early. `SOUND_LATENCY_MS` (200, a first guess, not measured) delays every visual; `?pitstopOffset=<ms>` overrides it per device (try 100–400, higher for Bluetooth) to find the right value, then bake it into the constant. Launch times are click-relative, everything else anchors to `playing`.
- **Clip source and cleanup.** Cut from a YouTube Short (2 stops in 20s; the first was used). Current filter is one chain over the whole region: `highpass=180` + `afftdn=nr=10:nf=-35` (the earlier 450 Hz highpass thinned the growl, whose body is 200–700 Hz, but it also cut more of the crowd/BGM bed: this is a tradeoff chosen for continuity, not verified by ear). A stem separator can't do this job (the Higgsfield tool splits vocals vs. rest, so gun noise stays bundled with the music). Build with `-ss/-t` on the input (one `filter_complex` with `atrim` + `afftdn` once produced a mostly digitally-silent file with no error) and re-verify any new cut on the *decoded* output with `silencedetect` and the near-silent-frame / level-drop check above, not the envelope of the mp3.
- **Magnet cost.** `pointermove` is rAF-throttled and skipped while the phase isn't `idle` (each pass reads every letter's rect).
- **Verify.** `npm run check:states` (confirmed failing with a raw `phaseRef.current =` write and with an extra edge), then drive the real page with `playwright-cli run-code --filename`: `click({ force: true })` is required because the idle drift in `HeroNameMotion` never lets Playwright's stability check pass. Measured on desktop: tires gone by ~160ms, near home at ≈ anchor + `BOLT_MS` + ~160ms spring, slide at ≈ anchor + `DRIVE_MS` (+ latency offset), re-entry from ≈ −1.15×viewport settling at 0, opacity always 1 and zero blurred elements, one `play()` per run even with a second click mid-run.
- **Effect deps must stay stable** in `usePitstop`: the cleanup flags the run dead, so a re-run mid-stop would strand the phase and leave clicks dead until reload.
